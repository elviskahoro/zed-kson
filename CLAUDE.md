# zed-kson

Zed editor extension for KSON (kson-org/kson). Rust, compiled to WebAssembly. Work in progress: see README.md "Status" for the two blockers (no Tree-sitter grammar, no published language server).

## Build & check

```bash
rustup target add wasm32-wasip2        # one-time; not installed by default
cargo check --target wasm32-wasip2     # the check that is known to pass
```

The crate is a `cdylib` against `zed_extension_api` 0.7.0, so it only builds for the wasm target. A plain `cargo check` on the host target is not meaningful.

There are no tests yet. To try the extension, use Zed's "Install Dev Extension" on this directory.

## Layout

- `extension.toml`: extension id/metadata and the `kson-language-server` registration. `[grammars.kson]` is deliberately absent until a Tree-sitter grammar exists.
- `src/lib.rs`: `KsonExtension`, the LSP adapter. It runs `node <binary.path> --stdio`, where the path comes from the user's `lsp.kson-language-server.binary.path` setting. Initialization options default to `distributionId = "kson"`, `enableBundledSchemas = true`.
- `languages/kson/config.toml`: language config (suffix `.kson`, `# ` line comments, brackets). It names `grammar = "kson"`, which will not resolve until the grammar is added.

## Conventions

- Keep the adapter dependency-light; the extension API is the only dependency.
- Do not add highlight, indent or injection queries without a grammar; they have nothing to attach to.
- Do not guess the server's CLI flags: `--stdio` is unverified upstream, and the README says so. Update the README whenever that changes.
- Commits use conventional-commit style, matching existing history (`Scaffold Zed KSON extension ...`).
